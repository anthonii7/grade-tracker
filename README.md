# Grade Tracker

A python program thats reads student grade data from a CSV file, then calculates averages, assigns letter grades, and then writes a formatted summarized report.
## Requirements
- python 3
- no external packages are required

## How to run
1. Make sure that the data folder contains students.csv
2. Open your terminal and navigate to the project folder
3. Run this command:

python3 grade_tracker.py

## Output

The program will print the summary to the terminal and create the file called grade_rep
ort.txt with the full class grade report.

## Files 

- grade_tracker.py -- main program
- data/students.csv - student grade data
- grade_report.txt - generated report, created when program is ran.
- requirements.txt - empty because built in python modules are used in the code
